# Формат выгрузки /anki

Как карточки в колоде PL-Tutor (пример — `07-czasowniki-lista.txt`).

- Текстовый файл UTF-8, одна карточка на строку, 4 поля через табуляцию, без заголовка.
- Имя файла: `NN-bot-YYYY-MM-DD.txt`.

| № | Поле | Пример |
|---|---|---|
| 1 | Перевод — тип — управление. **Без подсказок другими числами/лицами/формами.** | `искать — -am/-asz — szukać czegoś (РОД.)` |
| 2 | Польская фраза с пропуском — перевод. Пропуск: первая буква + `_` на каждую оставшуюся букву той формы, что стоит во фразе | `S_____ apteki. — Ищу аптеку.` |
| 3 | Словарная форма | `szukać` |
| 4 | Транскрипция, ударный слог заглавными | `ШУ-качь` |

Поле 1 по частям речи:
- глагол: `перевод — тип спряжения (-am/-asz, -ę/-isz, -uję/-ujesz, НЕПРАВИЛЬНЫЙ) — управление, если есть`;
- существительное: `перевод — род (м. р. / ж. р. / ср. р.)`;
- прилагательное: `перевод — прил.`;
- остальное: `перевод — часть речи`.

Правила:
- Пропуск в поле 2 считает код, не модель.
- Источники слов: слова наборов, 🆕 новые слова из разговоров, исправления типа «слово»; без дублей.
- `/anki` — только новое с прошлой выгрузки, `/anki all` — всё.
- Фраза — по возможности из реального разговора ученика, иначе простая придуманная.

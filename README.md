# bot-pl

Telegram-бот для разговорной практики польского: исправляет явные ошибки, подсказывает польские слова вместо русских, отвечает текстом (с транскрипцией и переводом) и голосом.

Схема: Telegram ⇄ бот (Docker на сервере) → Cloudflare Worker (Варшава) → Gemini API. Голос: edge-tts + ffmpeg.

## Команды

- `/menu` (и `/start`) — 🏠 главное меню: новый разговор, упражнения, наборы, итог, словарь, выгрузка; вверху — что идёт сейчас
- `/new` — 💬 новый разговор:
  - 🎯 тренировать текущий набор;
  - 📚 вернуться к набору из архива;
  - ➕ новый набор — по теме / свои слова / 📘 из юнита / 🧩 из ошибок / ⭐ из словаря (наборы тем словаря по 10 слов);
  - 🏁 без набора — без темы / 🗂 своя тема / 🎲 случайная тема
- `/ex` — 🏋️ упражнения: слова (пропуски), 🎙 голосом, грамматика по темам, мои частые ошибки, 📘 учебник
- `/words` — 📖 слова юнита по темам (🗂 оглавление сверху, слова учебника и тетради 📒 вместе в своей теме; темы, где меньше 3 слов, и слова без темы — в «Разное» в конце): весь список с транскрипцией, переводом и пометками (✅ — выучено); 🙈 скрытый перевод — по сообщению на тему (номер-кнопка → перевод одного слова), 📄 файлом, 🔊 озвучка по темам, частями до 30 слов
- `/phr` — 💬 полезные выражения (отдельно от учебников, кнопка в главном меню): блоки (сейчас «На каждый день») из циклов по ~10 выражений на одну тему (9 циклов); у каждого выражения — как читать, перевод и 📐 правило, которое оно показывает (если есть); разбиты по темам. Тренируются как юнит: список, скрытый перевод, файл, озвучка, карточки, тест, пропуски, набор для разговора (/set → 📘 из юнита → «Полезные выражения»), прогресс «знаю / узнаю». Лежат в `bot/textbook/phr/` (книга с `standalone: true` — в списке учебников её нет); новые части добавляются вместе с Claude.
- `/read` — 📚 чтение (кнопка в главном меню): книга по главам и абзацам по 4–5 предложений — текст по-польски, перевод под спойлером, 🔊 аудио в обычном темпе (озвучено заранее, при старте бота, кэш `data/audio/read/`), 📖 слова абзаца с переводом и правилом — ⭐ в словарь, ❓ вопрос по абзацу. Процент прочитанного по книге и главам, «▶️ Продолжить» с места остановки. После главы — 📝 вопросы к главе (как упражнения из книги) и 🎯 тренировка слов главы (как юнит). Сейчас: `bot/textbook/leg/` — 4 польские легенды, пересказанные для A1; книги для чтения — папки с `"reading": true` в `book.json`, главы с `paragraphs`.
- `/tw` — 🗣 скороговорки и песенки (кнопка в главном меню): 10 скороговорок по звукам (sz/cz/ż, ś/ć/dź и носовые, r/l/ł, длинные слова) и 10 считалок и народных песенок. Пункт — текст, транскрипция и перевод под спойлером, 💡 на что обратить внимание, аудио 🐢 медленно и 🔊 в обычном темпе — озвучено заранее при старте бота и хранится в `data/audio/tw/`, поэтому каждый раз одинаковое. Отметка в списке и в карточке: ⚪ не начато → 🟡 работаю → ✅ готово → ⚪; «🎲 Случайная из незавершённых». Тексты — `bot/content/zvuki.json`. 🎙 Проверка произношения: открыл карточку — пришли голосовое (в течение 30 минут): бот разберёт каждое слово с неверным звуком в формате «слово — как сказал — как правильно [транскрипция] — перевод», с подсказкой, как поставить язык. Ошибки идут в общий пул (правила «Произношение: …»), под результатом — «🙅 Не ошибка», как в разговоре.
- `/set` — 🎯 наборы слов: прогресс, новый набор, 📚 архив, отметить освоенные
- `/itog` — итог за час / сутки / разговор: ошибки по правилам, слова; всё время — файлом
- `/dict` — словарь ⭐ по темам: все слова одним списком (✅ — освоено), кнопки тем → слова темы и её наборы (🎯 разговор, 🏋️ упражнение); у слова — 📂 сменить тему (переезжает в набор новой темы вместе с прогрессом; своя тема = свой набор, можно собирать слова из разных тем) и 🗑 удалить; 🤖 «Разложить «Разное» по темам» — разовая раскладка старых слов моделью; 📄 файлом; `/dict add слово, слово` — добавить своё; 🙅 исключения
- `/rule вопрос` — объяснить правило своими словами
- `/export` — выгрузить всё файлом в любой момент: ошибки по правилам, слова, словарь
- `/cancel` — отменить текущий выбор, `/help` — подсказка

**Отмена ничего не сбрасывает.** «✖️ Отмена», `/cancel` и любая команда посреди выбора просто закрывают выбор и показывают главное меню; текущий разговор, его тема, набор и прогресс остаются как были. Новый разговор начинается только когда ты его выбрал в `/new`.

На каждом шаге выбора (/new, /ex, создание набора, /dict, /rule) внизу кнопки **⬅️ Назад** (вернуться на шаг с прежним выбором) и **✖️ Отмена**. Под выданным упражнением — «✖️ Закончить без проверки».

Под ответами бота: **📖 Правило** (разбор правил по ошибкам этого сообщения), **⭐ В словарь** — меню приходит сразу, без модели: 🧩 мои ошибки из этого сообщения (исправленный фрагмент с транскрипцией), 💬 «Подобрать из ответа» (модель выбирает 7–8 выражений, 5–15 с, результат запоминается), ✍️ свои слова; 📂 куда положить — 🤖 тему каждому слову подберёт ИИ (по возможности из уже существующих) или все отмеченные — в выбранную / новую тему; «✅ Готово» — слова ложатся в наборы тем «⭐ Еда 1», «⭐ Еда 2»… по 10 слов (в 📚 архиве, текущий набор не сбивается). Слова из 📚 чтения — в тему «Из чтения».

**⭐ В словарь из любого раздела** — кнопка под результатом упражнения из книги (кроме правда/неправда и свободного ответа), упражнения бота (в т. ч. карточки и тест по словам юнита), под /itog и под проверкой скороговорки. Меню то же: ❌ ошибки и пропуски отмечены сразу, ✅ остальное (в итоге — 🗣 сказанное по-русски), ✍️ свои слова, 📂 куда. Слово сохраняется в той форме, как в ответе; если это не именительный падеж — с пометкой падежа: «kawę (B.) — кофе (вин.)» (форма, перевод слова и тема — один запрос к модели, low). 🛡 Дубли: слово в той же форме уже в словаре — не добавляется, в меню помечено ⭐ «уже в «Еда»», нажатие — где лежит и перенести (первой кнопкой — в свою тему меню, если выбрана); после «✅ Готово» — список «уже были» с кнопками переноса. Так же для /dict add. и **🙅 Не ошибка**.

**🙅 Не ошибка** — отметить исправления, которые бот сделал зря (например, расслышал dokładne вместо dokładnie). Отмеченное уходит из пула ошибок (/itog, выгрузки, наборы и упражнения из ошибок), серия слова набора, сброшенная этим сообщением, восстанавливается, а пара «было → стало» попадает в исключения: такую же замену бот больше не показывает, а последние 30 исключений подсказываются модели. Под проверкой упражнения — **🙅 Оспорить** (пункт станет ✅, уйдёт из ошибок и с повтора). Список исключений — /dict → «🙅 Исключения». Бот верит на слово и не перепроверяет.

## Первый запуск на сервере

```powershell
cd E:\Bots
git clone https://github.com/Olbog/bot-pl.git
cd bot-pl
copy .env.example .env
notepad .env        # вписать TELEGRAM_TOKEN и PROXY_TOKEN, ALLOWED_USER_IDS пока пустой
docker compose up -d --build
```

Напиши боту что угодно — он ответит «Нет доступа. Твой Telegram ID: …». Впиши этот ID в `ALLOWED_USER_IDS` в `.env` и перезапусти:

```powershell
docker compose up -d
```

## Наборы слов

- В режиме набора бот строит разговор так, чтобы ты употреблял слова набора как можно чаще и в разных формах (лица, числа, падежи, времена).
- Каждое употребление слова отмечается: форма и правильно ли. Под ответом строка `🎯 piekę ✓ · ciasta ✗`.
- «Освоено» — 20 правильных употреблений (ошибка не засчитывается, но и не обнуляет набранное), минимум 3 разные формы, в 3 разных дня (`MASTER_*` в `.env`). Или отметь сам в `/set` → «Отметить освоенные».
- 👌 Знакомые — слова, которые уже свободно используешь: кнопка «👌 Знакомые» под ответом бота (слова из этого ответа) или `/set` → «👌 Знакомые слова». Вопросы на них не строятся; они возвращаются по одному, когда с последнего употребления прошло 2 круга по остальным словам (2 × число незнакомых ответов, минимум 6), и продолжают копить счётчик. Из набора уходят только при освоении. Если незнакомых не осталось — все слова снова в обычном режиме.
- Когда освоено 90% набора, бот предлагает следующий. Ничего никуда не переезжает: прошлый набор целиком, с прогрессом, уходит в **📚 архив** (/set → «📚 Архив наборов» или /new → «📚 Вернуться к набору»). Там незавершённые сверху (с датой последней тренировки), завершённые ниже; «▶️ Продолжить тренировку» делает набор снова активным — с того же места.
- 📘 Набор из юнита — до 10 невыученных слов юнита (сначала с ошибками). Употребление этих слов в разговоре идёт и в прогресс набора, и в прогресс юнита (как ответ RU→PL).
- Активный набор один. Тренировать его — /new → 🎯.
- Освоенные слова повторяются в свободном режиме через 3, 7, 14, 30, 60 дней.
- Отметки ставит модель — счётчики приблизительные, у Lite-моделей точность ниже.

## Ошибки и правила

- Каждая ошибка относится к правилу из каталога (`bot/core/rules.py`), поэтому ошибки группируются стабильно; новые примеры добавляются к уже известному правилу.
- Старые ошибки без правила раскладываются по каталогу автоматически при запуске (пачками по 40, 1 запрос на пачку).
- Набор «🧩 Из ошибок»: выбор периода, правила по убыванию числа ошибок, 🎲 случайные 3, по желанию короткое правило перед стартом.
- «Освоено» для правил в 2 раза строже, чем для слов: 40 раз подряд, 6 ситуаций, 6 дней.
- Автосохранение раз в неделю, в понедельник в 04:00 (Мск): полная выгрузка в `data/exports/` и файлом в чат. День и час — `AUTOSAVE_WEEKDAY` / `AUTOSAVE_HOUR` в `bot/settings.py`.

## Упражнения (/ex)

- В каждом упражнении 10 пунктов, количество упражнений задаёшь сам (1–20).
- Ответ одним сообщением: `1 piję 2 lubi 3 kupuje` (тест: `1b 2a`).
- Тест (варианты) — интерактивный: одно сообщение, под ним по строке кнопок на пункт («1 a · 1 b · 1 c · 1 !»); выбор можно менять, «!» — уверен, не объяснять. Уточнение — текстом «2 (почему …?)». Внизу «📨 Проверить (N/10)» — проверка, когда отмечены все. Ответ текстом тоже работает (недостающие пункты берутся из кнопок). Выключить — `EX_QUIZ_BUTTONS` в `bot/settings.py`.
- Уточнение или вопрос к пункту — в скобках: `1 piję (ja → -ę) 2 lubi (почему не lubią?)`. Ответ — то, что вне скобок; уточнение бот проверяет отдельно (💭) и отвечает на вопрос. Верный ответ с неверным рассуждением — ошибка (идёт в пул и /itog). В голосовом: скажи «уточнение» — всё до следующего предложения или «пункт N» считается уточнением.
- Маркеры НУ / ? сейчас выключены (`UNSURE_MARKERS` в `bot/exercises/logic.py`).
- Объясняется каждый пункт, даже верный. Уверен — поставь `!` (`3 kupuje!`), и этот пункт объяснять не будет (`EX_EXPLAIN_ALL` в `bot/settings.py`).
- Пока все упражнения только в настоящем времени (`EX_PRESENT_ONLY` в `bot/settings.py`).
- 📖 Правила (перед упражнением, «📖 Правило» под ответом, «Правила по ошибкам», /rule) объясняются целиком: суть, 📋 таблица всех форм / окончаний (по родам, основам, лицам), ⚠️ исключения и особые группы уровня A1–A2 (dzieci, ludzie, -owie, чередования), примеры с транскрипцией.
- ✍️ Своя тема сохраняется как написана (раньше подменялась ближайшим пунктом каталога и обрезалась); пункт каталога используется только для подбора прошлых ошибок на повтор.
- 🧩 Грамматика: формат (тест / свой ввод) → тема: 🔁 из моих ошибок (частые правила, период 14 дней или всё время), 🕘 недавние темы, 📐 из списка правил, ✍️ своя тема, 🎲 случайный микс → по желанию короткое правило → количество.
- Одна тема — все 10 пунктов на неё. Несколько — поровну вперемешку, на различение; в разборе каждого пункта — почему эта тема, а не другая.
- Если речь о глаголе — в разборе упражнения и в ✏️ исправлениях строка 🔤: инфинитив [транскрипция] — перевод · тип спряжения: формы ja, ty, oni. Тип спряжения у неправильных глаголов и у -ować ставит код (`bot/verbs.py`), у остальных — модель.
- Голосовые упражнения: читаешь все предложения целиком по порядку одним голосовым.
- 🎙 На любое упражнение (пропуски, тест, карточки, грамматика, упражнения из книги) можно ответить голосовым вместо текста: номер и ответ — «один — jestem, три — mam» (номера по-польски или по-русски, в любом порядке; без номеров — по порядку), «не знаю» — пропуск, «уточнение …» — вопрос к пункту. Один запрос к Gemini: модель распознаёт и сразу проверяет; в разборе видно, что расслышано. Оценивается звучание, а не написание: если из-за произношения получилась другая форма (pije вместо piję) — ошибка, лёгкий акцент — только замечание. В упражнениях из книги модели отправляются только ещё не верные пункты; пропуски до последнего названного номера — ошибка, как в тексте.
- Проверка: точные совпадения проверяет код (без запроса к Gemini), ошибки, сомнения и неоднозначные ответы — Gemini одним запросом. В разборе всегда форма (род, число, падеж, лицо, время), правило, полное предложение с транскрипцией и переводом, при пользе — аналогия с русским/белорусским (🌉). Под ошибкой или пропуском — 🇷🇺 перевод пункта и короткое задание (маска, вопрос до 40 символов), чтобы не листать вверх к упражнению.
- Без польских букв (`pije` вместо `piję`) — ошибка.
- Вопрос по пункту после проверки: `5: почему не czasem?`.
- У каждого упражнения номер #N; ответ через «Ответить» на сообщение с упражнением засчитывается именно ему. Пока бот составляет или проверяет, он пишет «⏳ …», а новые нажатия получают «ещё обрабатываю».
- Уникальность: все выданные предложения хранятся в базе (`ex_items`), повторы отсекаются. Повторяются только пункты с ошибкой или сомнением (🔁, до 3 на упражнение).
- Ошибки из упражнений идут в общий пул (видны в `/itog`, наборах и упражнениях «Мои ошибки»).
- Правильный ответ по слову или правилу текущего набора засчитывается в «освоено»: написал сам — с весом 0.1, выбрал в тесте — 0.05 (`EX_WEIGHT_TYPED` / `EX_WEIGHT_TEST` в `bot/settings.py`; только в серию, не в формы и дни).

## 📘 Учебник (/ex → 📘 Учебник)

**🔁 Повторить** — под результатом любой проверки: та же серия (вид, формат, юнит, направление, темы, слова, количество) одной кнопкой. В первое упражнение попадают ошибки только что проверенного: в учебнике — те же слова, в остальных упражнениях — **новые** предложения на то же правило и форму; остальное — новое.

- Учебники — папки `bot/textbook/<книга>/`: `book.json` (название, подпись юнита, папка аудио) и юниты `unit_NN.json` (название, суть, слова с переводом, транскрипцией и пометкой части речи, упражнения из книги). Сейчас: `kpk/` — Krok po kroku A1 (учебник + рабочая тетрадь, Units 1–12 и 7a), `hurra/` — Hurra!!! Po polsku 1 (Lekcje 1–10). Добавляет Claude по страницам PDF из `Books/`, потом ship + deploy.
- 📖 Правило к упражнению из книги: кнопка «📖 Правило» под упражнением и под результатом проверки — до, во время и после; меню «Всё упражнение» или пункты: номера — переключатели ☑️, можно отметить несколько и нажать «📖 Объяснить выбранные (N)» — одно объяснение на все: общее правило — один раз, разные — по отдельности, с пометкой «(пункты 3, 5)». В ответе «3?» (или «3? 5?») — проверка ответов + полное правило к этим пунктам одним сообщением (только отметки — правило без проверки), голосом «три — правило». Объяснение сохраняется в базе (`rule_cache`) — повторно мгновенно и без запроса к модели; «🔄 Объяснить по-другому» — заново.
- Если учебников с юнитами несколько — сначала выбор учебника, потом юнита (в /ex → 📘, /words и наборе из юнита). Ключ юнита — «книга:номер» (`kpk:8`); старый прогресс («8») перенесён в `kpk:8`.
- Слова юнита — из учебника и рабочей тетради (📒 — слово из тетради), разложены по темам: у слова поле `topic`, порядок тем — `topics` юнита; сочетание — в теме своего слова. Темы меньше 3 слов автоматически уходят в «Разное». Сами слова не выбрасываются — меняется только порядок вывода.
- Выбор юнита (с кратким описанием) → режим:
  - 📝 Упражнения из книги — упражнения учебника 📗 и тетради 📒 в формате Telegram: пропуски, выбор, «соедини», prawda / nieprawda, ответы на вопросы, свободный ответ. Картинки из книги заменены текстом с русской подсказкой или эмодзи. Отвечать можно частями, номера — в любом порядке («5 banan 1 jabłko»); «4-» — не знаю, «4-8-» — с 4 по 8 не знаю. Пропущенные пункты до последнего названного номера и «не знаю» — ошибка с правильным ответом; пункты после него — на потом. Если в ответах упражнения есть цифры (цены), новый пункт — с новой строки, после «;» или «.». Результат каждого пункта хранится (таблица `book_ex`) — ▶️ Продолжить позже. В длинных списках независимых пунктов (от 10) верные скрываются. Попытку добиваешь до 100% — её ответы сохраняются (`book_ex_done`, 📜 «Выполненная попытка» — все ответы сразу), «🔁 Выполнить заново» начинает новую попытку, прошлая не теряется. **✋ Засчитать вручную** (описка, спорный ответ): «5+» — пункт 5, «4+8+» — с 4 по 8; после проверки — «✋ Засчитать ошибочные»; в упражнении — «✋ Засчитать всё упражнение» (с подтверждением). Такие пункты помечаются ✋. Список показывает ✅ всё верно / ☑️ 100%, но часть засчитана вручную (✋N — сколько) / ◐ начато / ○ не начато и 🏆 — сколько раз сделано на 100% (🏆✋ — последний раз с ручными). Аудио к упражнению бот берёт из `Books/<папка аудио>` — своя папка у учебника и у тетради (`audio_dir` в `book.json`), ищет и в подпапках. Пути к папкам и PDF сверяются нестрого (регистр, пробелы, «_», польские буквы), поэтому «Krok po Kroku» на сервере и «Krok_po_kroku» на ноутбуке — одна и та же папка. Кнопка «📄 Страница учебника / тетради» присылает картинкой страницу книги из PDF в `Books/` (диалоги, таблицы, рисунки к упражнению): номер страницы берётся из ссылки упражнения («s. 54»), сдвиг между страницей книги и PDF — `page_offset` в `book.json`. Картинки вырезает `pdftoppm` (poppler-utils в Docker-образе) и кэширует в `data/pages/`.
  - ✍️ Пропуски в предложениях — польское предложение с пропуском; перевод пропущенного слова в русском переводе спрятан ([💡3]) — кнопка 💡3 под упражнением покажет его только для этого пункта (спойлер Telegram открывает сразу все, поэтому кнопки).
  - 🃏 Карточки — дано слово, пишешь перевод (🇵🇱→🇷🇺 / 🇷🇺→🇵🇱 / вперемешку). Точное совпадение — кодом, синонимы и спорное — Gemini; объясняются только ошибки.
  - 🔘 Тест — слово и 3 варианта, близких по смыслу (подбирает Gemini), ответ кнопками a / b / c.
- Сначала идут слова с ошибкой, потом ещё не «знаю», потом реже тренированные.
- Выученность — два уровня: **✅ знаю** — 3 раза подряд написал сам верно, в обе стороны (карточки, пропуски, разговор по набору из юнита); **🟡 узнаю** — 3 раза подряд верно выбрал в тесте. Ошибка в тесте сбрасывает оба уровня, ошибка в написании — только «знаю». Прогресс, накопленный до этого изменения, засчитан как «узнаю».
- 🔗 Сочетания с предлогами и устойчивые (płacić kartą, chleb z masłem, mieć ochotę na kawę…) — отдельные пункты юнита сразу под своим словом; тренируются как слова. Пока только с изученными падежами (`EX_CASES`).
- Ответы идут только в статистику юнита (таблица `book_stats`), не в общий пул ошибок и не в /itog.
- В пропусках слова ставятся в разные лица, числа и падежи — только из `EX_CASES` в `bot/settings.py` (сейчас именительный, винительный, творительный). Изучил новый падеж — добавь его туда.
- PDF и аудио учебников лежат в `Books/` — на ноутбуке и на сервере (`E:\Bots\bot-pl\Books`: `Krok po Kroku\A1 lvl`, `Hurra_po_polsku\1` — внутри PDF учебника и тетради и папки аудио к ним), в git не попадают (`.gitignore`). В контейнер папка подключается только для чтения (`./Books:/app/Books:ro` в `docker-compose.yml`).

## Модели и лимиты

Бот идёт по цепочке моделей от лучшей к худшей (`DEFAULT_MODELS` в `bot/ai/gemini.py`, переопределяется `GEMINI_MODELS` в `.env`).
У каждой модели свой дневной лимит бесплатного тарифа, поэтому цепочка складывает их:

- кончился дневной лимит — модель пропускается до сброса квоты (полночь по тихоокеанскому времени ≈ 10:00 Мск);
- минутный лимит или перегрузка — модель пропускается на время от нескольких секунд до минуты;
- модели нет в API — она убирается из цепочки при запуске (видно в логе «Цепочка моделей: …»).

Gemma работает без строгой схемы ответа; голосовые она может не принимать — тогда их обрабатывают только модели Gemini.
Под каждым ответом мелким шрифтом видно, какая модель ответила (`SHOW_MODEL=0` — скрыть).

Текущие лимиты: https://aistudio.google.com/rate-limit

# bot-pl

Telegram-бот для разговорной практики польского: исправляет явные ошибки, подсказывает польские слова вместо русских, отвечает текстом (с транскрипцией и переводом) и голосом.

Схема: Telegram ⇄ бот (Docker на сервере) → Cloudflare Worker (Варшава) → Gemini API. Голос: edge-tts + ffmpeg.

## Команды

- `/set` — набор: прогресс, новый набор по теме / из своих слов / 🧩 из ошибок / ⭐ из словаря, отметить освоенные
- `/free` — свободный разговор (с повторением давно не звучавших освоенных слов)
- `/itog` — итог за час / сутки / разговор: ошибки по правилам, слова; всё время — файлом
- `/dict` — словарь ⭐; `/dict add выражение` — добавить своё
- `/rule вопрос` — объяснить правило своими словами
- `/export` — выгрузить всё файлом в любой момент: ошибки по правилам, слова, словарь
- `/new` — начать разговор заново, `/cancel` — отменить шаг, `/help` — подсказка

Под ответами бота: **📖 Правило** (разбор правил по ошибкам этого сообщения) и **⭐ В словарь** (7–8 полезных выражений на выбор).

## Первый запуск на сервере

```powershell
cd E:\Bots
git clone https://github.com/Olbog/bot-pl.git
cd bot-pl
copy .env.example .env
notepad .env        # вписать TELEGRAM_TOKEN и PROXY_TOKEN, ALLOWED_USER_IDS пока пустой
docker compose up -d --build
docker compose logs -f   # должно быть «Бот запущен», выход — Ctrl+C
```

Напиши боту что угодно — он ответит «Нет доступа. Твой Telegram ID: …». Впиши этот ID в `ALLOWED_USER_IDS` в `.env` и перезапусти:

```powershell
docker compose up -d
```

## Порядок обновления

1. Claude правит код в `D:\Castro_2\Job\Bot\bot-pl` и кладёт описание коммита в `COMMIT_MSG.txt`.
2. На ноуте: `.\ship.ps1` — коммит и push.
3. На сервере: `cd E:\Bots\bot-pl; .\deploy.ps1` — pull, пересборка, тесты, лог.

Если PowerShell пишет, что выполнение скриптов отключено:
`powershell -ExecutionPolicy Bypass -File .\deploy.ps1` (так же для ship.ps1).

Код запекается в образ, поэтому deploy.ps1 делает `--build`, простого restart недостаточно.

## Наборы слов

- В режиме набора бот строит разговор так, чтобы ты употреблял слова набора как можно чаще и в разных формах (лица, числа, падежи, времена).
- Каждое употребление слова отмечается: форма и правильно ли. Под ответом строка `🎯 piekę ✓ · ciasta ✗`.
- «Освоено» — 20 раз подряд без ошибок (ошибка сбрасывает серию), минимум 3 разные формы, в 3 разных дня (`MASTER_*` в `.env`). Или отметь сам в `/set` → «Отметить освоенные».
- Когда освоено 90% набора, бот предлагает следующий; неосвоенные слова переезжают в него.
- Освоенные слова повторяются в свободном режиме через 3, 7, 14, 30, 60 дней.
- Отметки ставит модель — счётчики приблизительные, у Lite-моделей точность ниже.

## Ошибки и правила

- Каждая ошибка относится к правилу из каталога (`bot/rules.py`), поэтому ошибки группируются стабильно; новые примеры добавляются к уже известному правилу.
- Старые ошибки без правила раскладываются по каталогу автоматически при запуске (пачками по 40, 1 запрос на пачку).
- Набор «🧩 Из ошибок»: выбор периода, правила по убыванию числа ошибок, 🎲 случайные 3, по желанию короткое правило перед стартом.
- «Освоено» для правил в 2 раза строже, чем для слов: 40 раз подряд, 6 ситуаций, 6 дней.
- Автосохранение раз в неделю, в понедельник в 04:00 (Мск): полная выгрузка в `data/exports/` и файлом в чат. День и час — `AUTOSAVE_WEEKDAY` / `AUTOSAVE_HOUR` в `bot/main.py`.

## Модели и лимиты

Бот идёт по цепочке моделей от лучшей к худшей (`DEFAULT_MODELS` в `bot/gemini.py`, переопределяется `GEMINI_MODELS` в `.env`).
У каждой модели свой дневной лимит бесплатного тарифа, поэтому цепочка складывает их:

- кончился дневной лимит — модель пропускается до сброса квоты (полночь по тихоокеанскому времени ≈ 10:00 Мск);
- минутный лимит или перегрузка — модель пропускается на время от нескольких секунд до минуты;
- модели нет в API — она убирается из цепочки при запуске (видно в логе «Цепочка моделей: …»).

Gemma работает без строгой схемы ответа; голосовые она может не принимать — тогда их обрабатывают только модели Gemini.
Под каждым ответом мелким шрифтом видно, какая модель ответила (`SHOW_MODEL=0` — скрыть).

Текущие лимиты: https://aistudio.google.com/rate-limit
